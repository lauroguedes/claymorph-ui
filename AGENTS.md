# AGENTS.md

## ui-sdk

This project uses ui-sdk Web Components (`@ui-sdk/web`, `@ui-sdk/core`). Each component registers its tags when you import its entry, e.g. `import "@ui-sdk/web/dialog"`. Default styles are imported once at each entry (`src/site/main.ts`, `src/showcase/main.ts`) via `import "@ui-sdk/core/web.css"`.

- Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read `node_modules/@ui-sdk/web/docs/llms.txt`.
- To build a new component, also search `node_modules/@ui-sdk/web/docs/core.md` by heading, and read `node_modules/@ui-sdk/web/docs/rendering.md` next to it.

## Clay UI

- `src/clay/` is a component library: clay web components that wrap ui-sdk parts, drawn by one shared WebGL2 engine (`engine.ts`) with a CSS fallback. Before using it, follow `skills/clay-ui/SKILL.md`.
- It ships to npm as `claymorph-ui` from `packages/claymorph-ui/`: `npm run build:lib` builds it from `src/clay/`. `src/clay/components/` hold the classes, with no side effects; `src/clay/entries/<name>.ts` registers one element and imports the ui-sdk parts it wraps. A new element needs an entry there. The site imports Clay by the package name, aliased to the source in `vite.config.ts` and `tsconfig.json`.
- `src/site/` is its docs site (`index.html`). `src/showcase/` is Clay Tunes (`showcase.html`), a music app built only from the components: use it as the reference for composing them.
- `src/site/content.ts` is the single source for the docs pages, `public/llms*.txt`, `public/docs/*.md` and `skills/clay-ui/references/components.md`. Those files are generated by `scripts/ai-files.ts`; edit the content, not the output.
- Demos live in `src/site/demos/<id>.html` (plus an optional `<id>.ts` that exports a setup function). The site shows the same file as the preview and the code.
